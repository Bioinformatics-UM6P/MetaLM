# MetaLM release roadmap

**Research at UM6P · College of Computing · Bioinformatics Laboratory**

This repository currently hosts a public project preview. The sections below describe intended releases, not resources already available.

| Component | Planned material | Status |
|---|---|---|
| Dataset | MetaGen-Inst records, provenance and curation guidance | In preparation |
| Model | MetaLM adapters, model card and inference examples | In preparation |
| Agent | MetaLM-Agent code, configuration and execution documentation | In preparation |
| Benchmarks | Evaluation tasks, scoring and reproduction protocols | In preparation |
| Examples | End-to-end metagenomics demonstrations | In preparation |
| Docs | Setup, architecture and usage documentation | In preparation |
| Scripts | Reproducibility and setup utilities | In preparation |

Publication, licenses, artifact availability and release timing will be confirmed when ready.
